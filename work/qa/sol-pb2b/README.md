# Исследование маршрутов Солбрайна на PB2

`game/tests/playthrough.gd` — штатный живой стенд. Запускать один экземпляр
с `--path game`; второй процесс Godot можно использовать для проверки записи.
Ограничивать процесс таймаутом. Команда живому стенду:

```sh
python3 work/qa/sol-pb2b/command.py '{"start":0,"heroes":[1],"steps":[[1,16],[1,4],[1,16]],"fast":true}'
python3 work/qa/sol-pb2b/command.py '{"steps":[[20,66]]}'
```

`start` явно начинает новый забег; без него продолжается текущий.
Команда ждёт свой ID в state.json до 75 секунд. Стенд сохраняет ввод,
состояние, трассу последней команды и current.png в docs/qa/playthrough/.
Сохранение отдельной попытки — копирование этих четырёх файлов в новую папку.
Не копировать их до получения совпадающего ID результата.

Для исследования готовых сценариев: Godot `--headless --path game --script
res://tests/sol_pb2_route_probe.gd -- /абсолютный/путь/config.json`.
Конфигурация: `{"out":"/абсолютный/путь/result.json","cases":[{"name":"test",
"entry":5,"steps":[[30,0],[118,2]]}]}`. Кнопки: Right=1, Left=2, Down=4,
Up=8, Start=16, B=64, A=128; значения складываются. Исследовательский стенд
завершается кодом 0 при выполнении всех сценариев, даже если герой погиб:
сам выход комнаты доказывается событиями `changed`/`STAGE CLEAR` и новым
живым повтором в playthrough.gd. Искать `SCRIPT ERROR` в журнале обязательно.

После сохранения результата команда `{"steps":[],"quit":true}` завершает
стенд кодом 0. Команда продолжения без `start` при запуске пропускается: новый
процесс требует явного штатного входа.
