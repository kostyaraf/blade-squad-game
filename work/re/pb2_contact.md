# Power Blade 2 — как вещь и герой касаются друг друга

Всё это лежит в банке 7 (`$A000`), рядом с самим героем, и работает от его
стороны: за кадр он обходит места и сам решает, кого задел.

## Обход — `$B250`

```
$042C := $042C EOR $80          ; мигание: бит 7 переключают каждый кадр
X := 6
если ($1C & 1) = 0: X := 7      ; чётные места в одни кадры, нечётные в другие
цикл:
    если $27 != 3        -> дальше   ; играем ли мы вообще
    если $049A = 0       -> дальше   ; герой уже мёртв
    если $0400,X = 0     -> дальше   ; место пусто
    если $04F2,X или $04B0,X не ноль -> дальше   ; вещь не на этом экране
    JSR $B285                        ; проверить касание
    JSR $B5D5                        ; выстрелы героя против этой же вещи
    X := X + 2
пока X < $16
```

Каждая вещь проверяется **через кадр**. Это не мелочь: вплотную пройти
мимо на большой скорости и не задеть — можно, и картридж это позволяет.

## Кого вообще проверяют — `$B285`

```
если $0400,X = $0C          -> выйти
если $049A = 0              -> выйти           ; герой мёртв
если $05B8 (оглушение героя) не ноль:
        если ($0416,X & $50) = 0 -> выйти      ; пока мигает, задевают не все
        иначе -> к проверке
иначе:
        $042C := $042C AND $7F                 ; снять мигание
        если ($0416,X & $88) не ноль -> выйти
```

## Короб героя

Зависит от его же пометки `$0416` (то есть от того, что он делает):

| условие | `$06` (насколько выше `$04C6` середина) | полуширина `$0A` | полувысота `$0B` |
|---|---|---|---|
| `$0416 & $08` | `$0C` | 4 | 9 |
| `$0416 & $10` | `$08` | 8 | 8 |
| иначе | `$0F` | 6 | 13 |

## Короб вещи

`$B768`: по типу берут пару байт — полуширина в `$12`, полувысота в `$13`.
Указатели на пары: таблица слов `$B7DC` для типов меньше `$50` и `$B7A4`
для `$50` и выше (номер уменьшают на `$50`). Разных коробов всего 26 на
все 90 типов; вот они по типам (полуширина × полувысота):

```

18: 7x2  7x7  3x3  7x7  7x7  7x7  7x15 7x7
```

Середина вещи по высоте — `$04C6,X` минус `$B44F[тип]`:

## Сама проверка — `$B2EF`

```
$08 := |$0508 - $0508,X|              ; вбок, по модулю
$09 := |($04C6 - $06) - $07|          ; вниз, по модулю; $07 — середина вещи
касание, если  $12 + $0A >= $08  и  $13 + $0B >= $09
```

Обычное «расстояние против суммы половин», в восьми битах.

## Что бывает при касании

```
если $0416,X & $40  -> $B4AF        ; своя, особая встреча
если $0416,X & $10  -> $B5A5
иначе               -> $B39E:
        если ($0416 & $10) и $9A не ноль -> ущерб не берут (костюм держит)
        иначе если ($0416,X & $02) = 0:
                $17 := 3; JSR $B698          ; удар: искры и звук
                если $049A,X = 0 -> выйти
        иначе -> $D6D4                        ; вещь кончается о героя
        и затем $B3C0 — ущерб
```

`$B3C0` — ущерб герою:

```
$00 := $B3EF[тип вещи]
$049A := $049A - $00                  ; здоровье
если стало 0 или меньше: $049A := 0, $05FA := 0, $94 := 0    ; смерть
JSR $C822 ($D4ED)                     ; отброс и мигание
```

`$B3EF` — сколько снимает каждый тип:

```
00: 01 01 01 01 01 01 01 01 01 01 01 01 01 01 01 01
10: 02 01 01 02 02 02 02 02 01 02 01 00 01 02 02 02
20: 03 01 02 02 02 02 02 02 02 02 01 03 02 02 02 02
30: 01 01 01 01 03 03 02 03 04 03 03 03 03 02 03 02
40: 03 02 01 00 03 02 03 00 03 00 02 03 04 00 00 03
50: 03 03 03 04 04 04 03 03 03 03 03 03 03 03 03 03
```

Ноль — тип, который не ранит вовсе (`$1B`, `$43`, `$47`, `$49`, `$4D`, `$4E`).

## Отброс

`$B36A` (по пути к `$B4AF`/`$B5A5`) ставит `$05B8 := $28` — сорок кадров
неуязвимости — и через `$C81C` даёт вещам ход `$18`. Сторона отброса
кладётся в `$0626`: `$FF`, если вещь кончается о героя; иначе 0, если герой
правее вещи, и 1, если левее.

## Пометка `$0416` — что она значит

Разряд, шесть отдельных битов; у героя и у вещи разные смыслы, но биты те
же самые. Из увиденного:

| бит | у вещи | у героя |
|---|---|---|
| `$01` | — | не брать ущерб (`$B353`) |
| `$02` | кончается, задев героя | — |
| `$08` | ставится при рождении (`$E4F5`) | короб 4×9, середина `$0C` |
| `$10` | своя встреча `$B5A5` | короб 8×8, середина `$08`; с `$9A` — костюм держит |
| `$40` | своя встреча `$B4AF` | — |
| `$80` | вещь не проверяют вовсе (`$B340`) | мигание, переключается каждый кадр |

## Что переносить

1. таблицы `$B44F` (середина по высоте), `$B3EF` (ущерб) и коробы из
   `$B7DC`/`$B7A4` — в `game/data/pb2/objects.json`;
2. обход через кадр по чётности места и `$1C`;
3. проверку `$B2EF` как есть, в восьми битах и с модулем;
4. `$B4AF` и `$B5A5` — отдельно, они ещё не разобраны.


## Выстрелы героя против вещи — `$B5D5`

Места 1..5 — то, чем герой стреляет. Их проверяют против той же вещи в том
же обходе, сразу после `$B285`.

```
если $05B8,X (оглушение вещи) не ноль -> выйти
если $042C,X отрицательно             -> выйти
для Y = 1..5:
    если $04B0,Y или $04F2,Y не ноль  -> дальше   ; выстрел не на экране
    если $0400,Y = 0                  -> дальше   ; места нет
    $06 := $B725[тип выстрела]                    ; половина его короба
    JSR $B606
```

`$B606` — можно ли эту вещь ранить:

```
если $0400,X = 0            -> нет
если $049A,X = $FF          -> нет      ; здоровье $FF — нерушимое
если $05B8,X не ноль        -> нет      ; ещё мигает от прошлого
если $0416,X & $DA          -> нет
если $042C,X отрицательно   -> нет
```

Короб — тот же `$B768`, середина — та же `$B44F`, и проверка та же:

```
$0A := |$0508,Y - $0508,X|
$0B := |$04C6,Y - $07|
касание, если  $12 + $06 >= $0A  и  $13 + $06 >= $0B
```

При касании:

* `$0416,X & $20` — броня: звук `$26`, `$05B8,X := $08`, вещь цела;
* иначе `$B688`: `$17 := $B721[тип выстрела]` и `$B698` — снять здоровье,
  затем ход вещам `$21`.

`$B721` = `01 01 02 03` — сила по типу выстрела; `$B725` = `05 08 09 10` —
половина его короба. (Какой тип какой цифре отвечает, ещё не сверено на
эмуляторе: ноль — «места нет», так что счёт, похоже, идёт с единицы.)

## Что здоровье вещи

`$049A,X` — третий байт записи уровня: `$E4D8` кладёт его туда при рождении.
Тот же байт у собираемого — его номер среди шестнадцати (`$E530`), так что
это не «здоровье», а поле на откуп типу: у врага — здоровье, у собираемого —
кто он. Вещи, рождённые обработчиком (`$F8A1` и соседи), его не задают
вовсе: у выстрелов и осколков там остаётся ноль.

`$FF` — нерушимое. `$B698`:

```
$049A,X := $049A,X - $17
если осталось больше нуля:
        тип < $50 -> $05B8,X := $08          ; мигнуть
        тип >= $50 -> $05B8,X := $10, и (кроме $53) JSR $C8C4
иначе — смерть:
        тип < $50:  здоровье, состояние и $0610,X := 0
                    $05FA,X := ответ $B729 (0 или 1)
                    JSR $B747                 ; что после себя оставить
                    $0400,X := $01            ; вещь становится взрывом
                    $0416,X := $80            ; и её больше не проверяют
        тип >= $50: состояние := $B717[тип - $50]   ; у больших своя смерть
```

Тип `$0C` умирает иначе: состояние `$02`, пометка `$80`.

Вещь не освобождает своего места, когда её убили: она **становится типом
`$01`** — взрывом — и доигрывает его. Место освобождает уже взрыв.
