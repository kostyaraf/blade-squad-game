# Полоса состояния Power Blade 2 (Э3.7)

Всё, что игра пишет в нижние шестьдесят четыре строки экрана, идёт одним
путём: не прямой записью в видеопамять, а очередью, которую кадр собирает и
которую опустошает обратный ход луча.  Здесь разобрана и очередь, и все семь
кусков полосы.

## Очередь `$0300`

`$1F` — куда писать дальше.  Четыре двери на запись, все они кладут один байт
и двигают `$1F`:

| адрес | что кладёт |
|-------|------------|
| `$CD18` | `$01` — начало записи, шаг вправо |
| `$CD1C` | `$02` — начало записи, шаг вниз (на `$2000` идёт `+$04`) |
| `$CD0B` | то, что в `A` |
| `$CD09` | `$FF` — конец записи |

Одна запись: **вид**, **младший байт адреса**, **старший байт адреса**, потом
содержимое.  Вид ноль — конца очереди, дальше ничего.

## Как её опустошают (`$CC41`, обратный ход луча)

```
CC47  LDX $0300,Y      ; вид
      BEQ CC70         ; ноль -- всё
      LDA $FF          ; то, что игра держит в $2000
      AND #$18
      ORA $CC3C,X      ; $CC3C = FF 00 04 00 00 -- вид 2 добавляет шаг вниз
      STA $2000
      INY
      LDA $2002        ; сбросить защёлку
      LDA $0301,Y      ; старший байт адреса
      STA $2006
      LDA $0300,Y      ; младший
      STA $2006
      INY / INY
```

Дальше по виду:

* **вид меньше трёх** — байты подряд, пока не встретится `$FF`.  Причём `$FF`
  кончает запись только если следующий байт меньше пяти (то есть похож на
  вид); иначе `$FF` пишется как обычная плитка и чтение идёт дальше
  (`$CC8A`).  Так `$FF` попадает в видеопамять, не ломая очереди.
* **вид ровно три** — `[сколько][чем]`, заливка.
* **вид больше трёх** — `[сколько]`, потом столько байтов.

Конец (`$CC70`): `$0300 := 0`, `$1F := 0`, `$2000 := $FF`.

`$CCBC` кладёт в очередь готовую полоску из таблицы `$CD28` (в самих
полосках `$FD` и `$FE` — свои управляющие байты).

## Три цифры из байта (`$D40A`)

Все числа полосы пишутся одним куском: вид 1, адрес из `$11:$10`, потом
старшая тетрада `$12` через `$CB06` плюс `$20`, потом младшая плюс `$20`,
потом `$FF`.  То есть цифра — это плитка `$20 + цифра`, и число хранится
двоично-десятичным.

## Семь кусков полосы

`$D650` — расписание.  По `$1B` из четырёх ходов, по одному ходу на кадр:

| `$1B` | что рисуется |
|-------|--------------|
| 0 | `$D431` этап и область (или полоса босса) и `$D489` счёт |
| 1 | `$D4A7`, `$D4B6`, `$D4C5` — три числа справа |
| 2 | `$D4ED` здоровье и `$D4D9` полоса костюма |
| 3 | `$D58D` заряд лезвия и `$D5C1` портрет костюма; `$1B := 0` |

### Этап и область — `$D431`

Только пока `$79` ноль (то есть не комната босса): полоска 2, потом
`$2724 := $53 + 1`, `$272B := $9C + 1` (и если младшая тетрада вышла
десяткой или больше, к ней прибавляется шесть — перенос вручную),
`$272E := $D483[$53]`, где `$D483 = 07 08 07 07 10 14`.

Если `$79` не ноль — полоска 3 и сразу полоса босса `$D522`.

### Время — `$D489`

`$26C3 := $95`, `$26C5 := $96` — четыре двоично-десятичных цифры, и это не
счёт, а **время**, которое идёт вниз.

**Откуда берётся.** `$CE45` (банк 14) при заходе в этап: по `$AD` (какая
половина) берут указатель из `$CE67`, а по `$53` (этап) — два байта; `$57`
гасят.

```
CE45  LDA $AD / ASL / TAY / ($CE67,Y) -> $00:$01
CE51  LDA $53 / ASL / TAY
CE55  ($00),Y   -> $96      ; младшие две цифры
CE5B  ($00),Y+1 -> $95      ; старшие
CE60  $57 := 0 / JMP $D489
```

| `$AD` | таблица | пять этапов |
|---|---|---|
| 0 | `$CE6D` | 0540 0570 0530 0560 0460 |
| 1 | `$CE79` | 0360 0400 0400 0380 0350 |
| 2 | `$CE85` | 0200 0200 0200 0230 0200 |

**Как идёт.** `$CA3A` из кадра уровня (`$CEFA`): стоит, пока `$58` не ноль
или пока время уже ноль, и тикает **раз в 64 кадра** (`$1C AND $3F`).  Если
`$57` поднят — ещё и звук `$34` каждый тик.  Само вычитание — `$CA59`:
единица из четырёх двоично-десятичных цифр вручную, с заёмом через все
четыре; на `0030` ставят `$57` := 1.

**Чем кончается.** `$A17A` (банки 8/9, из `$8E23`) — та же проверка, что и
на смерть от жизни: `$95` или `$96` не ноль — живёт; оба нуля — герой
умирает (`$049A` := 0, `$058C` := `$20`, `$0442` := `$16`).

**Когда заводят заново.** `$CE45` зовут из двух мест: шаг `$1A` = 2
(`$CE14` — подготовка этапа) и `$D063` (потеряна жизнь).  Дверь идёт через
`$1A` := 6 → 3 и шага 2 не проходит, значит **дверь времени не трогает**.
Последнего босса (`$79` = 0, `$53` = 5, `$9C` = 0) бьют вовсе без часов:
`$CEEC` обходит `$CEFA`.

Таблицы `$CE67` — по шесть этапов, а не по пять: шестая запись есть у каждой
из трёх половин (`0800`, `0450`, `0450`).

### Три числа справа — `$D4A7`, `$D4B6`, `$D4C5`

`$2736 := $9D`, `$2739 := $9E`, `$273C := $9F`.

### Полосы

Все четыре одной формы: восемь плиток, счёт идёт сверху вниз, из числа
вычитается вес одной плитки, а остаток на последней плитке выбирает
половинку из маленькой таблицы.

| что | откуда | адрес | вес плитки | целая | остатки |
|-----|--------|-------|------------|-------|---------|
| здоровье `$D4ED` | `$049A` | `$26E8` | 2 | `$38` | `$D520 = 3A 39` |
| костюм `$D4D9` | `$A0` | `$2708` | 2 | `$38` | те же |
| заряд `$D58D` | `$54` | `$26AE` | 2 | `$35` | `$D5BF = 9F 36` |
| босс `$D522` | `$04A9` | `$2728` | 4 | `$38` / `$2B` | `$D585 = 3A 39 39 39`, `$D589 = 38 2D 2D 2D` |

Полоса босса — две в одной: пока `$04A9` меньше `$20`, она рисуется первым
набором, а с `$20` и выше из числа вычитается `$20` и берётся второй.  Так
восемь плиток показывают шестьдесят четыре единицы здоровья двумя цветами.

### Портрет костюма — `$D5C1`

`$9A` (какой костюм надет) умножается на два и берёт указатель из `$D619`:
`$D623`, `$D62C`, `$D635`, `$D647`, `$D63E` — **третий и четвёртый
переставлены местами** относительно порядка плиток.  По указателю лежат
девять плиток, три ряда по три:

```
$D623  50 51 52 / 60 61 62 / 70 71 72
$D62C  53 54 55 / 63 64 65 / 73 74 75
$D635  56 57 58 / 66 67 68 / 76 77 78
$D63E  59 5A 5B / 69 6A 6B / 79 7A 7B
$D647  5C 5D 5E / 6C 6D 6E / 7C 7D 7E
```

Ряды кладутся тремя отдельными записями по адресам из `$D613`: `$26F1`,
`$2711`, `$2731`.

## Готовые полоски — `$CD28`

Десять указателей: `$CD3C`, `$CD44`, `$CD4F`, `$CD5E`, `$CD67`, `$CD3C`,
`$CD3C`, `$CD74`, `$CDA2`, `$CD96`.  Полоска — это адрес (младший, старший) и
за ним буквы до `$FE`; `$FD` внутри полоски значит «дальше новый адрес».

Буква — это её номер в азбуке: `$01` = A, `$1A` = Z, `$00` — пробел, цифры
идут с `$20`.  Так, полоска 2 (`$CD4F`) — это `ST   AREA` по адресу `$2722`,
а полоска 3 (`$CD5E`) — `ENEMY` по тому же адресу: в комнате босса на месте
этапа и области стоит слово.

## Когда её рисуют

Полосу не перерисовывают каждый кадр.  Один раз её собирают целиком, когда
уровень строится, и дальше трогают только тот кусок, чьё число изменилось.

`$1A` — счёт из тринадцати ходов, которым уровень строит себя (`$CDD3`).  Ход
первый — `$CE11`, а это и есть расписание `$D650`: четыре кадра, по куску за
кадр, и последний из них ставит `$1B` обратно в ноль и двигает `$1A` дальше
(`$D685`).  Ход шестой (`$CF3C`) — уже сама игра.

Дальше каждый кусок зовут с места, где меняется его число:

| кусок | откуда зовут | что там случилось |
|-------|--------------|-------------------|
| заряд `$D58D` | `$D252` (из `$D23A`) | кнопку держат, `$54` подрос |
| заряд, портрет | `$D030`, `$D033` | герой погиб, всё сброшено |
| здоровье `$D4ED` | `$D05D` | новая жизнь, `$049A := $10` |
| третье число `$D4C5` | `$D055` | `$9F` убавилось на единицу |
| второе число `$D4B6` | `$D303` | костюм кончился, `$9E` убавилось |
| полоса костюма `$D4D9` | `$D30F`, `$D316` | `$A0` убавилось или кончилось |
| портрет `$D5C1` | `$D320`, `$D29D` | костюм сменился |
| счёт `$D489` | `$CA56`, `$CE64`, `$CFF7` | очки прибавились |
| этап и область `$D431` | `$CF89`, `$CFE1` | вошли в область |

`$D2D4` — расход костюма: из `$85:$86` каждый кадр вычитается вес из
`$D326[$9A-1]`, и когда шестнадцать тысяч кончились, `$A0` убавляется на
единицу и полоса перерисовывается.

`$D243` — заряд: `$54` доводится до потолка `$D255[$55] = 04 08 0C 10`, по
единице за кадр, и после каждой единицы полоса перерисовывается.

## Кто ещё кладёт байт в очередь

В очередь пишут не только куски полосы, и это важно для приёмки: если не
знать про эти два места, их байты припишутся куску, который рисовали
последним.

| место | что кладёт |
|-------|-----------|
| `$CC41` | ноль в начале выдоха, чтобы очередь кончалась там, где она кончилась |
| `$CD14` | ноль в конце кадра (`$EA3D`) — кадр закрывает список сам |

`$CD14` — это отдельная дверь в `$CD0B`: `LDA #$00 / BEQ $CD0B`.  Зовут её из
одного места, `$EA3D`, сразу после того как собран список спрайтов.

Отдельная дверь есть и у полосы босса: `$D522` зовут не только из `$D47B`
(этап и область, когда босс на экране), но и из `$C8C4` — когда босса ударили.
Поэтому она кусок сама по себе, а `$D431` при боссе рисует только слово
ENEMY.
