# Power Blade 2 — как двигается вещь

Всё, что не герой, ходит по одним и тем же нескольким подпрограммам в
постоянном банке 15. Обработчик типа сам никогда не складывает место со
скоростью: он только задаёт скорость и зовёт общий шаг. Поэтому движение
переносится один раз и сразу для всех девяноста типов.

## Место и скорость

Место — три байта на ось, скорость — два, оба со знаком:

| ось | старший | младший | дробный | скорость ст. | скорость мл. |
|---|---|---|---|---|---|
| вниз  | `$04B0,X` | `$04C6,X` | `$04DC,X` | `$0534,X` | `$054A,X` |
| вбок  | `$04F2,X` | `$0508,X` | `$051E,X` | `$0560,X` | `$0576,X` |

Младший байт места — точка на экране (0..255), старший — сколько экранов
в сторону, со знаком. Дробная часть — 1/256 точки.

Скорость `$0534`:`$054A` читается как 16 бит со знаком: `$054A` — 1/256
точки за кадр, `$0534` — целые точки за кадр.

## Шаг

`$FA0B` (переходник `$C8F4`) — шаг вниз:

```
$00 := 0
$04DC,X := $04DC,X + $054A,X          ; дробная часть, перенос дальше
если $0534,X отрицательна: $00 := $FF ; знак растянуть на третий байт
$04C6,X := $04C6,X + $0534,X + перенос
$04B0,X := $04B0,X + $00 + перенос
```

`$FA2F` (`$C8F7`) — то же вбок, поля `$051E`/`$0576`/`$0508`/`$0560`/`$04F2`.

`$FA08` (`$C8F1`) — обе оси: сперва вбок, потом вниз.
`$FA05` (`$C8EE`) — сперва шаг картинки (`$E30F`), потом обе оси.

Порядок важен: вбок раньше, чем вниз.

## Сдвинуть на месте, без скорости

`$FA55` (`$C92D`) — прибавить к месту вниз `A`:`Y` (`A` — дробная часть,
`Y` — целая, со знаком); `$FA53` (`$C930`) — то же с `A` = 0.
`$FA75`/`$FA73` (`$C933`/`$C936`) — то же вбок.

## Скорость

| зовут | что делает |
|---|---|
| `$F9BD` (`$C909`) | скорость вниз := `A`:`Y` |
| `$F9B5` (`$C906`) | скорость вбок := `A`:`Y` |
| `$FA93` (`$C90C`) | к скорости вниз прибавить `A` как дробную часть — это тяжесть |
| `$FAA3` (`$C912`) | к скорости вбок прибавить `A` |
| `$FAB3` (`$C90F`) | из скорости вниз вычесть `A` |
| `$FAC7` (`$C915`) | из скорости вбок вычесть `A` |
| `$F99F` (`$C921`) | сменить знак скорости вниз (16 бит) |
| `$F980` (`$C918`) | сменить знак скорости вбок |
| `$F97D` (`$C91B`) | то же и повернуться |
| `$F989` (`$C91E`) | повернуться: бит 6 в `$042C,X` наоборот |

Тяжесть — именно `$FA93` с дробным шагом: 16-битная скорость растёт на
`A`/256 точки за кадр, и обработчик сам решает, сколько это `A`.

## Куда смотреть

`$F9DC` (`$C8FA`) — герой слева или справа. Перенос **сброшен**, если герой
правее (вещь ушла за него вбок), и **взведён**, если левее:

```
если $04F2,X < 0        -> перенос сброшен   ; вещь левее экрана, герой правее
если $04F2,X > 0        -> перенос взведён
иначе                    -> сравнить $0508,X с $0508 (местом героя)
```

`$F9C5` (`$C8FD`) — повернуться к герою: бит 6 в `$042C,X` ставится, когда
перенос сброшен, и снимается, когда взведён.

`$F9EE` (`$C900`) — задать скорость вбок, повернуться к герою и, если вещь
смотрит влево (бит 6), сменить знак скорости. `$F9F7` (`$C903`) — то же без
поворота к герою: скорость задают, а знак берут из того, куда вещь уже
смотрит.

## Расстояние до героя

`$FB25` (`$C93C`) — вбок: если вещь не на экране героя (`$04F2,X` не ноль),
перенос по знаку, переполнение взведено; если на экране — вычитание
`$0508,X - $0508`, перенос из него, переполнение сброшено, и при
отрицательной разнице она берётся по модулю (`$CAEB`).

`$FB4B` (`$C93F`) — то же вниз, поля `$04B0`/`$04C6`.

Читать так: переполнение сброшено — вещь и герой на одном экране и в `A`
лежит расстояние; взведено — далеко, и `A` бессмысленна.

## Через кадр и вразбивку

`$FB81`:

```
A := (X EOR $0119) AND 1
```

`$0119` растёт на единицу каждый кадр (`$8017`). Ноль — «сейчас моя
очередь». Этим дорогой запрос местности разносят по кадрам: чётные места
спрашивают в чётные кадры, нечётные — в нечётные, и за кадр работы вдвое
меньше. Каждая вещь при этом опрашивает местность раз в два кадра.

`$FB88` (`$C945`): `$10 := A`, и если очередь не моя — вернуть `A = 0`,
иначе спросить местность в точке `A` вбок, `Y` вниз (`$F342`).
`$FB92` (`$C948`) — то же, но не в свою очередь возвращает `A = $80`
(«упёрлось»), а не «пусто».

`$FB73`/`$FB7B` (`$C8EB`/`$C8E8`) — шагнуть и умереть, если пришло:

```
$FB73: A := 0, Y := 0
$FB7B: JSR $FB88            ; спросить местность под собой
       если ответ отрицателен -> $D6D4 (стереть место, смерть)
       иначе                  -> $FA08 (шаг по обеим осям)
```

## Что из этого следует для движка

Один общий шаг на все типы: три байта места, два байта скорости, дробная
часть переносом. Никаких дробей с точкой — только целые, как в картридже.

Разбивка через кадр (`$FB81`) — не украшение, а часть поведения: вещь,
которой очередь не выпала, местность не видит и в этот кадр сквозь неё
проходит. Без этого она будет останавливаться на кадр раньше.
