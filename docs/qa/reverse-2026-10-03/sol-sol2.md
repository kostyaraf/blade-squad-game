## Дефекты

### SSB-20 — s19: после победы над финальным боссом концовка стоит вечно

- Уровень: s19.0 (вход 82); герой: Солбрайн (`1`), один.
- Нажатия/тик: запись `s19-sol` до тика 1500 (босс добит ≈ 1480), дальше без нажатий.
- Ожидаемое: шаг концовки `$9EB5` (`$58` = 7) сам ведёт героя к боссу (пишет в `$06` RIGHT/LEFT после `$9E73`), пока расстояние не меньше 24 px; затем шаги 8…20 и STAGE CLEAR.
- Наблюдаемое: `$58` = 7 навсегда, герой стоит на x 880, босс — на 913 (разница 33 px); 1600+ тиков ничего не происходит.
- Причина: в паре `Pb3Pair._walk_sol` при `controls_locked` все пады обнуляются, и кнопки, которые сценарий записал в `$06`, герою не доходят. В ROM герой читает `$06` из памяти (`$94CA AND $06`, bank 12), сценарий пишет его раньше (`$CDB3`).
- Исправление: при `controls_locked` герои-Солбрайны получают `host_sol.six` (`$06` после сценария); герои PB2 по-прежнему без кнопок. Разница с ROM: `$04` (новые нажатия) герой считает сам из `$06`, а не берёт у сценария — для шагов `$A026` (A держится) это даёт одно нажатие вместо нажатия каждый кадр; на концовку не влияет.
- Проверка: запись `s19-sol` — STAGE CLEAR 3556 (до правки — нет выхода). `pb3_sol_end_hold_test`, `pb3_sol_boss_walk_test`, `pb3_sol_door_rearm_test`, `pb3_sol_exits_test` (0 из 280), `pb3_session_test` (0 из 59244) — код 0, без SCRIPT ERROR; `verify_pb3_playthrough.py` 0 из 40.
- Не тронуто: одиночная игра (`SolTurn.step`, `main.gd`) отдаёт герою пад игрока, а не `$06`, — там концовка проходит, если игрок сам подойдёт к боссу. Не в зоне PB3-пары, отмечено для координатора.
- Коммит: SSB-20 (см. `git log`). Слито с NSB-20 (`nova-sol2`, 0311b72) — та же причина: в итоге остаётся одна версия NSB-20, где все удерживаемые герои (и Нова, и Солбрайн) получают `$06 | $04` сценария; мой цикл только для Солбрайна убран. После слияния `s19-sol` даёт тот же STAGE CLEAR 3556; тесты выше и `verify_pb3_playthrough.py` (0 из 44) — код 0, без SCRIPT ERROR.

## Наблюдения

- s15: пол из горячих труб (класс `$18`) ранит при касании; ворота id 8/9 (по 8 жизней) у x 1104/1232 надо разбить; полубосс id 65 (32 жизни) в комнате (3,7), x 784…1007, стены-ворота `?` открываются после него. HP по ходу этапа тает: восстанавливает только панель «костюм» (плитка 48 для s15, присесть на ней, цена 30 очков; очки — за врагов). Панели s15: щит (84) у (1568,1472); костюм (48) у (1536,1968), (288,2240), (2112,2304), (3232,432); «подарок» (196, для s15 — костюм) у (2432,1696), (1920,2464). После смены этапа на месте (`$55` = 16) герой берёт таблицу панелей s16 (`unpack` пишет `hero.stage`).
- s19: шаг `$A091` ждёт x героя ≥ 704; ворота `$915B` превращают босса в бойца (mind `$30`); побеждён ударами вплотную (x≈880) без урона. Падающий объект id 31 у героя — уходить в сторону.
- s13: лифт едет вверх сам (после NSB-03); босс id 65 летает рядом с героем и сбрасывает ряды снарядов id 128 по высоте лифта; спутник id 1 добивается боссом за ≈400 тиков. Стоять на лифте и бить вверх/в сторону при подлёте; урон в основном от контакта и рядов снарядов.
- s15, комната (5,9) — сверка с картриджем (`nesemu` + `sol_probe.warp` в этап `$0F`, герой и камера поставлены в комнату): порт совпадает. Это комната полубосса 2: сценарий `$9AA0` ждёт, пока камера дойдёт до `$31` = `$50` (герой x ≥ ≈1410), запирает комнату и выпускает босса id 65 (64 жизни, волны огня по полу). После его смерти (`$0600` = 0, ≈390 кадров анимации) шаг `$9B67` снимает стену x 1520: в картридже и в порту гаснут одни и те же биты `$054E` (`$18`), герой проходит вправо. В попытке 1 герой стоял у x 1377 и босса просто не вызвал. Дефекта нет.
- s15, очки: подбираемые очки (5 или 20) оставляют только «свои» враги этапа с id < `$20` (`$A989` → `$A9AB`); враги ряда 9 и дальше (id 34…44) ничего не оставляют. Поэтому к панелям «подарок» (1920,2464) и «костюм» (2112,2304) герой приходит с 15 очками при цене 30 — восстановить HP там нельзя. Щит стоит 10, «попытка» — 200.
- s16 → s19: условие `$9DBF` — герой в костюме, колонка `$CB` (x ≈ 3240…3255), `$83` = `$16` (стоит на y 368), `$05A2` = 0 и поза `$05A6` ∈ {`$64`,`$68`,`$DA`} (стоит/присел, не идёт). Просто пробежать по точке мало — надо остановиться.
