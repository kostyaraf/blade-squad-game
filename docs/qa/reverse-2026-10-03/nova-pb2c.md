## Дефекты

**NPB2-20 — p5.0: Нова падает в дверь и гибнет, пока дверь закрывается (исправлен).**
Уровень p5.0 (вход 39), Нова, без нажатий. Ожидаемое (картридж): шахта
проходится падением; кадр 1333 — касание двери (`$27=4`, `$2A=1`), герой
замирает на строке `$C3`, кадр 1365 — `$1A=6`, следующая область p5.1.
Наблюдаемое: на тике 236 дверь закрывается (`$04` состояние 5), но Нова
падает дальше и на 237 гибнет ниже строки `$C7` — «TEAM DOWN».
Причина: в картридже, пока стоит `$2A`, свой ход получают только двери
`$03/$04` (`$802F`); герой в слоте 0 тоже ждёт — его шаг `$8E1D..$8E52`
(броски, движение, `$A17A`) не выполняется (трасса: `$A17A` после 1332 не
вызывается, `$04C6` стоит `$C3`). `Pb2Turn.step` вызывал шаг героя всегда.
Исправление: при `world.frozen` шаг героя, бросков и спутников пропускается
(`game/src/pb2_turn.gd`). Проверка: `npb2_door_freeze_test.gd` (герой стоит
32 тика до перехода, как 1333→1365; exit 0, без SCRIPT ERROR);
`verify_pb3_playthrough.py` 0 из 39; `verify_run.py` 0 из 59.
Остаток: касание в порте на кадр раньше (строка 190, картридж — `$C3`=195);
на прохождение не влияет, не исправлялось.
