# Вопросы nova-pb2c

## К REV-04 / GAP-18 — исходный этап `$53` при отдельном входе в p6.0–p6.4

**Найдено.** Ревью (REV-04) считает, что p6.0–p6.3 достижимы только с
`$53=5`. Байты картриджа это опровергают. Банк 10, `$86E7` (дверь `$04`,
последняя область этапа):

```
86FF A0 00     LDY #$00
8701 A5 53     LDA $53
8703 C9 05     CMP #$05
8705 F0 01     BEQ $8708
8707 A8        TAY            ; Y = $53 для этапов 0..4
8708 84 9C     STY $9C
```

(байты сверены прямо в `Power Blade 2 (USA).nes`: `A0 00 A5 53 C9 05 F0 01 A8 84 9C`).
Значит последняя дверь этапа s = 0..4 ведёт в 6:s с `$53=s`; этап 5 — в 6:0,
а `$891D INC $9C` ведёт его цепочку 6:1…6:4 с `$53=5`. Данные это
подтверждают: двери `$04` есть в последней области каждого этапа
(p0.6, p1.7, p2.6, p3.6, p4.9, p5.13), а непрерывная цепочка p0 Новы
(`p0-nova-pb2b`) штатно входит из p0.6 в p6.0 и бьёт босса `$50`.

То есть **каждая** из p6.0–p6.4 неоднозначна так же, как p6.4 в GAP-18:
либо босс своего этапа (`$53=s`), либо шаг финальной цепочки (`$53=5`).

**Варианты:** те же, что в GAP-18, но для всех p6.0–p6.4:
1. `$53 = номер комнаты` — босс своего этапа (сейчас так, формула NPB2-01).
2. `$53 = 5` — шаг финальной цепочки.
3. Две записи списка на каждую комнату.

**Сейчас.** Исправление REV-04 не применено: вариант «только `$53=5`»
противоречит ROM для обычного прохождения этапов 0–3. Оставлено `came = ar % 6`.
