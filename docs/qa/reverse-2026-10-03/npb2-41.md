# NPB2-41 — отрисовка движущегося потолка p1.0 (часть прежнего NPB-06)

- Уровень: p1.0, герой Нова, kind 4. Дефект передан из
  [nova-pb2.md](nova-pb2.md), NPB-06.
- Ожидаемое: верхняя часть комнаты движется вместе с потолком,
  пустая полоса отделяет её от неподвижного пола; изображение совпадает
  с картриджем и движущейся границей столкновений.
- Наблюдаемое до исправления: граница столкновений меняется, фон остаётся
  неподвижным. При обычном входе 7 и ожидании движение потолка не видно.
- Причина: `main.gd` передавал один scroll для всей комнаты. Значения
  `Pb2Objects.water` (`$29`) и `draw` (`$FC`) обновлялись, но IRQ-полосы
  фона не передавались шейдеру.
- ROM: `$EAF7/$EAFF` выбирают IRQ kind 4 и первую границу `$29`;
  таблицы `$E65B/$E67D` задают обработчики `$E7AC/$E7DA/$E70D`.
  `$E7AC` переключает CHR на пустые банки; `$E7DA` восстанавливает
  обычные банки и фиксированную нижнюю часть через PPUADDR `$25C0`.
  В банке 14 `$D15F..$D168` задают второй IRQ, `$D13B` двигает
  границу и scroll, `$D177` задаёт оборачивание scroll.
- Исправление: общий `_pb2_raster` передаёт полосы в существующий шейдер
  для одиночного PB2 и PB3. Верх использует `(screen_y + draw) % 240`,
  пустая полоса начинается на `water + 1`, неподвижный низ — на строке
  130 с `map_y = screen_y - 16`. Банки `[100,101,100,101]`, границы,
  смещение и период извлекаются `work/extract/pb2_raster.py` из ROM
  и снимков PPU в `game/data/pb2/raster.json`; в движке они не зашиты.
  Координаты спрайтов не меняются.
- Проверка: `python3 work/extract/verify_pb2_raster_kind4.py` —
  **0 / 277 760 пикселей фона**, семь кадров неизменённого картриджа
  (1450, 1500, 1600, 1700, 1800, 2100, 2300), включая оборачивание
  верхнего scroll. CHR-полосы сверены по строкам; восстановленный
  NES-фон сверён со снимками вне маски спрайтов. Затем настоящий
  OpenGL-шейдер Godot сверён с NES-фоном по всем пикселям поля
  x=8..255, y=16..175. Exit 0, без `SCRIPT ERROR`.
  Диагностические состояния из PPU используются только для проверки
  отрисовки; временные снимки удалены.
- Обычный повтор: штатный вход **7**, Нова, **200 IDLE**, без подмены
  состояния. На тике 200 потолок виден в новом положении, герой жив,
  HP 16, энергия 16, ended 0. Кадр просмотрен.
  [Запись ввода](../playthrough/p1.0-npb2-41/replay.json),
  [состояние](../playthrough/p1.0-npb2-41/state.json),
  [кадр](../playthrough/p1.0-npb2-41/current.png).
  Это повтор дефекта с начала комнаты, а не прохождение до выхода.
- Граница исправления: только kind 4. Kind 6 (p1.5) и kind 9 (p3.6)
  имеют другую цепочку IRQ; оставшаяся часть NPB-06 здесь не закрыта.
  Регрессию сохранённых маршрутов выполняет основной исполнитель;
  результат этой проверки здесь пока не заявлен.
- Коммит: `NPB2-41: render PB2 moving ceiling from ROM IRQ bands`.
