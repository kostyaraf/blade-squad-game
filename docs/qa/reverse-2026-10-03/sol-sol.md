## Дефекты

### SSB-01 — нет мигания подобранной первой/второй буквы α/β

- Уровень: s0.0; герой: Солбрайн (`1`); модульная диагностическая расстановка ROM, не прохождение.
- Нажатия/тик: IDLE; ROM savestate 2320, буква в точке героя на 2330; подбор 2331.
- Ожидаемое: `$070C` либо `$070D` получает `$20`, затем убывает. Третья буква не запускает этот таймер.
- Наблюдаемое: `SolObjects._suit()` пропускает запись (`pass`), таймер остаётся 0.
- Причина: не перенесены `$82EB` (α) / `$8329` (β), `LDA #$20; STA $070C,Y` bank 8.
- Исправление: `SolObjects._suit()` пишет `w_kind[0x0C + which] = sat_table.letter_blink` (байт `$82EC` = `$20`, извлекается `work/extract/sol_sat.py`).
- Проверка: `work/extract/verify_sol_pickups.py` (ROM s0 кадр 2320, буква на герое) — 0 из 8 (α/β × первая/вторая/третья/полный набор); без правки — 4 из 8. `game/tests/sol_pickups_test.gd` также проверяет, что мигание гаснет за 32 картинки. Регрессия: `verify_sol_sat.py` 0 из 144, `verify_pb3_playthrough.py` 0 из 11.
- Коммит: SSB-01 (см. `git log`).
