## Дефекты

### SSB-01 — нет мигания подобранной первой/второй буквы α/β

- Уровень: s0.0; герой: Солбрайн (`1`); модульная диагностическая расстановка ROM, не прохождение.
- Нажатия/тик: IDLE; ROM savestate 2320, буква в точке героя на 2330; подбор 2331.
- Ожидаемое: `$070C` либо `$070D` получает `$20`, затем убывает. Третья буква не запускает этот таймер.
- Наблюдаемое: `SolObjects._suit()` пропускает запись (`pass`), таймер остаётся 0.
- Причина: не перенесены `$82EB` (α) / `$8329` (β), `LDA #$20; STA $070C,Y` bank 8.
- Исправление: `SolObjects._suit()` пишет `w_kind[0x0C + which] = sat_table.letter_blink` (байт `$82EC` = `$20`, извлекается `work/extract/sol_sat.py`).
- Проверка: `work/extract/verify_sol_pickups.py` (ROM s0 кадр 2320, буква на герое) — 0 из 8 (α/β × первая/вторая/третья/полный набор); без правки — 4 из 8. `game/tests/sol_pickups_test.gd` также проверяет, что мигание гаснет за 32 картинки. Регрессия: `verify_sol_sat.py` 0 из 144, `verify_pb3_playthrough.py` 0 из 11.
- Коммит: SSB-01 (см. `git log`).

## ROM-сверки и взаимодействия

Наблюдения из прохождения s0.0 (запись `s0.0-sol`), проверенные по ROM или по переносу кода ROM:

- Ящики (обычные и низкие 16 px — только DOWN+B), колонны из ящиков, стенные ползуны, турели (бомбы можно сбить ударом), роботы, сетка (UP в прыжке — зацепиться, A — оттолкнуться и перелезть столб 64 px), шахты с проваливанием, буквы α/β (подбор, счёт), предмет «P», переход в босса — работают.
- Предмет «P» из ящика у x≈2264,y≈760 (id `$80`, поведение 6, картинка 62) не подбирается касанием и исчезает по таймеру. ROM: та же подкладка в s0 (кадр 2330, слот `$0B`) тоже не подбирается — поведение родное, не дефект.
- После «двойного» оружия герой ~80 кадров стоит в состоянии `$0D` (сгорание), позже — в `$0F/$10`; это перенос `$97D4`/`$9816`/`$982E`, не дефект.
- Узкая коробка героя: буква подбирается только при почти полном наложении (≈2 px), так написано в `$81B7`.
- Босс s8: прыгает на правую стену, пускает две искры по периметру комнаты (по полу — перепрыгивать), бросает снаряд, который делится на три осколка; садится у x≈3476. Бить одиночным ударом с x≈boss−27 и сразу отходить: при стоянии ближе ~35 px он задевает. Победа на 14752.
- Выход s0 → s8: срабатывает, когда герой прыгает на машину у (3232–3262, 1970) и стоит на ней у x=3244 (запуск на 9012); стоя на x=3257, 120 кадров не сработало. С ROM не сверено — см. «Непроверенное».
