# Вопросы исполнителя `items`, 2026-10-03

Только новые вопросы и конкретные случаи к существующим GAP из `docs/pb3-gameplay-questions.md`. Правила не придуманы: везде сохранено текущее поведение порта.

## Новые вопросы

### ITMQ-01 — может ли оружие гостя переворачивать α/β и открывать «?»

В Solbrain выстрел героя переворачивает букву α ↔ β и открывает «?». В PB3 оружие гостя (Нова в уровне Solbrain, второй Солбрайн) по предметам не попадает: `arms_hit` их пропускает. Гость может только подобрать предмет таким, какой он есть.

Варианты: разрешить любому герою; только Солбрайнам; оставить как есть (тогда выбор буквы — только у хозяина).

Связано с GAP-02 и GAP-11, но там вопрос о награде и о преградах, а не о попадании по предмету.

### ITMQ-02 — порядок выпадения общий на пару или у каждого свой

В PB2 следующий выпадающий предмет определяется счётчиком `$98` (каждая смерть врага двигает его). В PB3 счётчик один на комнату, в пуле хозяина: убийства обоих героев двигают общий порядок, и кто убил — не важно. После ITM-02 счётчик живёт через двери, как в картридже.

Варианты: оставить общий (как у одного героя в картридже); вести у каждого героя свой.

## Случаи к существующим GAP

### GAP-01 — кто получает бонус Power Blade

- NN, p0.x: капсулу или выпадение подбирает P2 — здоровье/бак/усиление получает P1 (`_pick_up` пишет в статус хозяина, слот 0).
- Солбрайн в PB2 при Нове-хозяине: всё подобранное Солбрайном уходит Нове.
- S и SS без Новы: здоровье из капсулы пропадает (некому), запасной бак уходит в невидимый статус хозяина.

### GAP-02 — что дают Нове буквы α/β

- N в Solbrain (нет Солбрайна-хозяина): три буквы создают видимого, но бездействующего спутника (ум 1, id 02) у запасного Солбрайна рядом с Новой; он не стреляет.
- NS: буквы, взятые Новой, идут в общий пул — спутника получает Солбрайн.
- SS: буквы P2 строят спутника P1.

### GAP-03 — монеты и панели

- NS, s0: Солбрайн выбил монету из куба, Нова подобрала — `bonus 0 → 20` в пуле Солбрайна-хозяина (запись `playthrough/s0-nova-sol-cube`).
- Нова на панели щита s0 (1216,400) ничего не покупает, даже при 200 очков в пуле.
- SS: монеты P2 идут в пул P1, а P2 на панели платит из своего пула — купить ему не на что.

### GAP-05 — свободный выбор и награды

- После сбора букв HUD показывает GUN 1 при спутнике уровня 2.

### GAP-07 — ненужный бонус

- Гость не может перевернуть α/β (ITMQ-01), поэтому ненужную ему букву остаётся только подобрать или оставить до исчезновения по таймеру.

### GAP-13 — что сохраняется при смене комнаты

- Порядок выпадения `$98` и взятые капсулы `$2B:$2C` теперь переносятся через дверь (ITM-02, как в картридже). Запуск комнаты из меню начинает их с нуля, как новая игра. Одиночный режим `main.gd` всё ещё обнуляет их на каждой двери — передано исполнителю `nova-pb2`.
