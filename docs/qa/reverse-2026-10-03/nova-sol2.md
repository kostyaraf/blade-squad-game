## Метод

Поиск маршрута — лучевой (beam search) по снимкам состояния сессии (`snap.gd` из набора `sol-sol`), только нажатия; найденный ввод проигрывается заново через `game/tests/playthrough.gd`. Инструменты — черновые, в `game/tests/_nsb2/` (не коммитятся). Снимок состояния копировал массивы и тем рвал общие ссылки между объектами: `guest_arms` хозяина и `arms` пары. После восстановления броски Новы переставали бить врагов Solbrain, и найденный путь при чистом повторе расходился. Теперь массивы восстанавливаются на месте, проверено: 0 расхождений. Это ошибка только инструмента, игра не затронута.

## Дефекты

### NSB-20 — s19: после победы над последним боссом концовка стоит на шаге $9EB5, герой не идёт к боссу

- Уровень/герой: s19 (вход 82), Нова 0, костюм 1. Касается и Солбрайна в PB3: кнопки под удержанием сценария отнимались у всех героев.
- Ввод: штатный вход, START/UP/START (костюм 1), RIGHT 400 тиков (шаги `$A091`…`$A0D0`, бой начат на ~400), LEFT 30, затем 110 раз LEFT+B / B / пауза 12; босс slot0 (HP80) побеждён с x924 к тику ~1000.
- Ожидаемое: шаг 7 концовки `$9EB5` держит героя (`$9E73` забирает `$04/$06`) и сам даёт ему `$06` = к боссу, пока расстояние (`$90/$91`) не меньше `$0280` шестнадцатых (40 px); затем шаги 8…20 и затемнение.
- Наблюдаемое: `$58` = 7 навсегда (проверено 2500 тиков), Нова стоит на x924 (до босса 76 px) — тупик, этап не кончается.
- Причина: `Pb3Pair._walk_sol` под удержанием (`controls_locked`) подавал героям нулевые кнопки. Кнопки, которые сценарий сам кладёт в `$06/$04`, не доходили ни до гостя, ни до героя Solbrain.
- Исправление: под удержанием каждый герой получает `$06 | $04` из памяти сценария (сценарий уже отработал в этом кадре: `$CDB3` раньше `$91B5`). Это перенос родного «сценарий ведёт героя», не новое правило.
- Проверка: новый `game/tests/pb3_sol_ending_walk_test.gd` (обычный ввод от входа s19): до правки `$58` = 7, провал; после — `$58` доходит до `$0F`, 0 провалов. `verify_pb3_playthrough.py` 0 из 38 расходятся; `pb3_sol_end_hold_test`, `pb3_sol_boss_walk_test`, `pb3_session_test` (0/59244), `pb3_sol_exits_test` (0/280) — код 0, без SCRIPT ERROR.
- Коммит: NSB-20.
