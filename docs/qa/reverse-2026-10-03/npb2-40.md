# NPB2-40 — отсутствующий ребёнок гнезда $1C (прежний NPB-01)

- Уровень: p1.7, герой Нова. Исходный дефект передан из
  [nova-pb2.md](nova-pb2.md): быстрый обход обнаружил `$1C` без поведения;
  точный тик прежний отчёт не сохранил.
- Ожидаемое: гнездо `$1B` создаёт видимого ребёнка `$1C` с 1 HP,
  который падает на пол, идёт к герою, падает с уступов и взрывается о стену.
- Наблюдаемое до исправления: слот `$1C` остаётся в состоянии 0,
  с нулевой картинкой; гнездо заполняет детские слоты неподвижными объектами.
- Причина: отсутствовал `$1C` в `Pb2Objects.MINDS`; алгоритм картриджа
  `$8E29..$8E9C` (банк 10) не был перенесён.
- Исправление: зарегистрирован `_mind_1c`, перенесены четыре состояния;
  значения извлекаются из ROM в `objects.json.nest_child_1c`.
  Проверки пола `$BEDD/$BEE3` сохранены с разными ответами вне своей фазы:
  воздух при падении, пол при ходьбе. При смене падения/ходьбы движение
  в том же тике не выполняется. Взрыв освобождает весь слот через 16 тиков.
- ROM: `$8E34` — инициализация, `$8E49` — падение, `$8E72` — ходьба,
  `$8E92` — срок взрыва. `$BEBF 00 FF` через `$F9EE` направляет скорость
  к герою; бит `$042C & $40` обозначает сторону увеличения координат.
- Дифференциальная проверка:
  `python3 work/extract/verify_pb2_nest_child_1c.py` — **0 / 853 760 полей**,
  40 постановок в p0.0/p1.7, все четыре состояния, обе фазы запроса
  местности, дробные координаты. Неизменённый картридж; exit 0,
  без `SCRIPT ERROR`. Временные трассы удалены.
- Фокусная проверка:
  `Godot --headless --path game --script res://tests/npb2_nest_child_test.gd`
  — **0 / 11 ошибок**, exit 0, без `SCRIPT ERROR`: родитель создаёт ребёнка,
  обычный обход запускает обработчик, появляются HP/картинка/скорость,
  шестнадцатый тик взрыва освобождает слот.
- Обычный повтор с начала p1.7: штатный вход **14**, Нова, выбор костюма 3
  кнопками `START, UP × 3, START`; затем 24 IDLE, 8 RIGHT+A+B,
  70 RIGHT+A+B+UP, 1 RIGHT, 8 RIGHT+A, 100 RIGHT+A+UP.
  Между отдельными нажатиями меню — по одному IDLE.
  `$1C` появился на тике **198**; на тике **220** слот 6 имеет type `$1C`,
  state 1, HP 1, экранные координаты (152,115). Нова жив, HP 16,
  энергия 15; `SCRIPT ERROR` нет.
