## 4. Как продолжить

1. Проверить диск (`df -g`), что нет старых процессов Godot/Codex.
2. `cd PB3-wt/integ && python3 work/extract/verify_pb3_playthrough.py` —
   должно быть «0 of N failed», без `SCRIPT ERROR`.
3. Для каждой незакрытой зоны запустить исполнителя в его копии:
   сначала `git merge --no-edit qa/reverse`, затем прочитать «Передача» в
   своём отчёте. Шаблон задания — промпты в `orchestration/` и BRIEF.
4. Раз в 60–90 мин сливать ветки исполнителей в `qa/reverse`
   (конфликт `cases.json` → `python3 ../union_cases.py`; конфликт в коде →
   поручить автору ветки слить `qa/reverse` у себя), затем
   `verify_pb3_playthrough.py`.
5. В конце: свести отчёты в `docs/qa/playthrough-checklist.md`, вопросы —
   в `docs/pb3-gameplay-questions.md`; спросить пользователя о слиянии

  зону». Лимит Codex: ~1 ч работы двух сессий; при «usage limit» — передать
  зону Claude (и обратно после сброса).
