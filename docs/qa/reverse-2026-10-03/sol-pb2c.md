# sol-pb2c — Солбрайн на этапах PB2 p4, p5, p6 (2026-10-03)

Герой `heroes:[1]`, ветка `qa/sol-pb2`. Движение — по картриджу Solbrain,
карта, объекты и боссы — PB2. Меню в начале: Start → Down → Start (ружьё 8).
Все записи — обычные нажатия, `exact_scan: true` (правило после SPB2-04).
Цепочка этапа идёт непрерывно от штатного входа первой комнаты.

## Как искался маршрут

Маршрут ищется перебором обычных нажатий (кнопки по кадрам) в копии игры
без окна. Найденная запись затем заново проигрывается с нуля в живом стенде
`game/tests/playthrough.gd` (код 0, без `SCRIPT ERROR`, те же тики выходов) —
только это считается подтверждением. Ни здоровье, ни положение, ни объекты
не подменяются.

- p4.1 (вертикальная шахта, экран сам уезжает вверх): подъём по балкам,
  наверху дверь (16,112) стоит в нише под низким навесом высотой 15 точек —
  туда Солбрайн проходит только подкатом (Вниз + A) влево.
- p4.3 — середина этапа (объект `$0E`, PB2 `$8B86`): уход влево за x=$90
  перестраивает ту же комнату во второй половине этапа (событие `changed`
  с тем же входом 32 на 3211), затем появляется дверь (16,128) слева.
