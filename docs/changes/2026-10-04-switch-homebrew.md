# SW-01 — тестовая сборка Switch из объединённого main

Источник игры: main c1ce69e; исходники game/ не менялись.
Homebrodot Godot 3.5.3 требует отдельного преобразованного проекта.
Инструменты и конвертер находятся в work/switch/, генерация — в build/.

## SW-01: новый код не загружался в Godot 3

Уровень: первый проверяемый вход PB3 с Новой; затронуты смешанные режимы.
Воспроизведение: запуск work/switch/entries.gd после преобразования main,
до первого тика. Ожидание: сессия создаётся и принимает обычные кнопки.
Наблюдение: Parse Error в pb2_as_sol.gd:138, затем FAILED ENTER и код 1.
Причина: Godot 3 не принимает конструкцию `src.kind not in [...]`;
старый конвертер исправлял только конкретное выражение `q.sub not in`.
Исправление: преобразовывать отрицательное членство для простых переменных
и цепочек свойств во всех преобразуемых скриптах.

Проверка: 83 входа, Нова/Солбрайн/пара, до 30 тиков каждого входа —
7422 записи кадров полностью совпали с исходным Godot 4, код 0 обоих
процессов, без SCRIPT ERROR. Графическая сцена PB3 и экспортированный PCK
проверены в Godot 3, код 0, без SCRIPT ERROR и SHADER ERROR.
Экспорт NRO/PCK завершён с кодом 0; NRO0 и CRC ZIP проверены.
Это не приёмка полных прохождений и не проверка на настоящей консоли.

## Файлы и ограничения

Архив build/PB3-Switch-v0.1.0.zip содержит /switch/PB3/PB3.nro и PB3.pck,
инструкцию, описание исходного коммита и лицензии движка/шрифта.
Папку switch нужно скопировать в корень SD-карты и запускать через
Homebrew Menu с полным доступом к памяти. Это NRO-приложение.
На консоли не проверено. Шаблон поддерживает один физический контроллер;
логика игры вдвоём сохранена, но второй контроллер требует другого шаблона.

Настройка Homebrew Menu: https://github.com/Atmosphere-NX/Atmosphere/blob/master/docs/features/configurations.md
