# История продукта PB3

Точка начала этого журнала — `eb78205`. Сведения о предыдущих изменениях
ниже восстановлены из Git и существующих QA-отчётов, а не из нового тестирования.
Каждая следующая запись описывает наблюдаемое поведение до/после, причину,
проверку, ограничения и связанный коммит. Старое состояние не переписываем;
уточнения добавляем новой записью. Текущий статус остаётся в `docs/status_ver3.md`.
