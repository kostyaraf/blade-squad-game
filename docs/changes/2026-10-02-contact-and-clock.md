# Владелец контакта и время между комнатами

Продолжение аудита после `b0cc965`.

## INT-03: способность принадлежит герою

**До:** для контактного удара подкатом PB2 читал костюм хозяина пула даже при
проверке другого героя. Представление второго Новы вообще не передавало его
родной флаг подката, поэтому костюм второго игрока не давал ожидаемую атаку.

**После:** представление гостя передаёт его состояние и костюм. Контактная
проверка использует их; родной одиночный путь продолжает читать родной костюм.
Солбрайн не получает чужой костюм через владельца уровня. Его отдельная атака
подкатом остаётся в системе гостевых атак.

**Проверка:** четыре сочетания костюмов первого/второго Новы. Весь контактный
проход по врагу с 3 HP: второй Нова в костюме убивает врага подкатом без урона
себе; без костюма получает урон, независимо от снаряжения первого.

## INT-05: дверь не начинает таймер заново

Независимое чтение исходников через Claude обнаружило, что PB3 создавал новый
таймер на каждой двери. Родной путь `main.gd` сохраняет его: `$CE45` вызывается
при новом входе/жизни/половине этапа, а не на обычном переходе.

Теперь оставшееся время, предупреждение, флаг истечения и дробная фаза счётчика
сохраняются на дверях и при входе к боссу. INTERLUDE по-прежнему начинает время
следующей половины. Правило восстановления здоровья здесь не менялось.

**Проверка:** одиночные Nova/Solbrain и смешанные пары обоих порядков;
дверь → босс → INTERLUDE. `verify_pb3_contracts.py`: **0 / 36 ошибок** суммарно.
Это диагностически вызванные переходы, не новое прохождение.
