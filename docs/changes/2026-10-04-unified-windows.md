# INT-01 — единая актуальная Windows-сборка PB3

4 октября 2026 пользователь запросил одну актуальную сборку вместо
отдельных main и QA, а также очистку кеша и временных файлов тестирования.

## Объединение

В qa/reverse объединены 35 исправлений реверсивного тестирования,
обновлённые анимации и результаты проверки маршрутов с main 0ddf2ff,
содержащим расширение игровой области PB2 до 224 строк.
Незавершённые правки основной рабочей копии не изменялись.

### INT-01: растровая прокрутка комнаты p0.7 и расширенный кадр

При объединении пересеклись преобразование экранных координат из GAP-17
и растровый эффект PB2 kind4 из QA. Специальный эффект делит изображение
на движущийся верх и фиксированный пол; верх имеет собственное зацикливание.

Ожидание: после сдвига изображения вниз на16px обе части и их палитры
остаются на своих исходных местах относительно героя. Старая область256×160
должна совпадать пиксель в пиксель.

Причина: выбор scroll/scroll2, граница верхнего зацикливания и выбор полосы
CHR использовали непосредственно FRAGCOORD.y. После расширения кадра эти
значения надо читать в родной системе координат, как уже делается для OAM.

Исправление: вычесть display_dy при выборе растрового участка и банка CHR;
сохранить top_wrap_y. В динамической комнате верхняя дополнительная полоса
использует существующий зацикленный фон. Тест отдельно проверяет это правило,
а статические комнаты — повтор крайних блоков. Стенд принудительно рисует кадр,
чтобы проверка не зависела от перекрытия окна другим приложением macOS.

Проверка: `pb3_display_test.gd` —509 проверок,0 ошибок; код0, без SCRIPT ERROR.
`verify_pb3_playthrough.py` —0 из62 принятых записей расходятся; код0,
без SCRIPT ERROR. Поставленные графические проверки не засчитывают новые
полные прохождения уровней.

## Единственный Windows-архив

`build/PB3-Windows-x64.zip`: Windows x64, Release, Godot4.6.1,
исполняемый файл и отдельный пакет PCK, инструкция и описание версии.
Сборка выполняется из объединённой qa/reverse; исходный main с незавершёнными
правками сохранён. Архив проверяется по CRC; пакет отдельно загружается Godot
на macOS. Запуск самого EXE в Windows здесь недоступен.

## Очистка

Удаляются устаревшие Windows-архивы и их промежуточные каталоги,
воспроизводимые дампы/изображения/логи work/tmp, work/tmp2 и work/dyn,
Python bytecode, временные QA-mailbox и результаты стендов /tmp,
пользовательские логи Godot PB3, неотслеживаемый кеш Godot.
Исходники вспомогательных инструментов, конфигурации, ROM, записи принятых
и неудачных прохождений, QA-отчёты, исследовательские эталоны и материалы
незавершённой анимации сохраняются. Отслеживаемый Git кеш классов и .uid
сохраняются по правилам проекта. Другие проекты и их временные каталоги
не очищаются.
